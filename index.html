My Projects

01

Instagram feed Design

This project focused on designing an Instagram feed for GAMAM based on a template-driven system that ensures both visual consistency and ease of use. The main goal was to create a set of posts that could be easily recreated, making the content production process more efficient and sustainable over time. At the same time, the system was designed to maintain a strong and cohesive visual identity, understanding that Instagram is a highly visual and aspirational platform. To achieve this, I developed a combination of flexible templates: some for quotes and short-form content, others for carousels, and additional formats focused on lifestyle imagery. Each template follows a consistent visual language while allowing enough variation to keep the feed dynamic and engaging. The result is a scalable and adaptable content system that balances aesthetics, functionality, and brand coherence.

02

Creation of a design system

This project focused on the creation of a design system for GAMAM’s website, aimed at improving visual consistency, user experience, and overall performance. The starting point was identifying key issues within the existing site, such as inconsistent color usage, lack of cohesion across UI elements like cards, and an overall fragmented visual language. These inconsistencies not only affected the user experience, but also limited the site’s scalability and clarity. To address this, I developed a structured design system that defined clear guidelines for color, typography, spacing, and component design. Special attention was given to standardizing elements like cards and content blocks, ensuring they worked cohesively across different sections of the site. Additionally, the redesign considered SEO improvements, aligning the visual and structural updates with better content organization and usability practices. The result is a more unified, scalable, and user-friendly digital experience, where design decisions support both aesthetic consistency and functional performance.

03

Personal Branding Design

This project focused on the creation of my personal branding as a designer, with the goal of building a visual identity that reflects both my creative style and my approach to design. The process began by defining the core concept behind my brand — a balance between creativity and structure — which later translated into visual elements such as color, typography, and composition. I aimed to create an identity that feels clean and intentional, while still allowing space for exploration and personality. Each element of the branding system was designed to be flexible and adaptable across different platforms, from digital portfolios to social media, ensuring consistency while maintaining a dynamic visual presence. This project allowed me to better understand my own design perspective, not just in terms of aesthetics, but in how I communicate ideas and connect with others through design.
